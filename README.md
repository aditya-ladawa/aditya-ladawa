The [code](https://github.com/aditya-ladawa/infra_peter) includes the parts between the LLM response and the published video.

## A few decisions you can inspect

In [PeCal Pulse](https://github.com/aditya-ladawa/pecal-pulse), our team compared several forecasting approaches. A simple historical baseline beat the more complex volume models. Activity prediction was a separate problem: logistic regression reached 0.81 ROC AUC on the historical holdout. The public demo uses synthetic data.

In the [Buena context engine](https://github.com/aditya-ladawa/buena-property-context-engine), new data updates a living property map. Source pointers let an agent go back to evidence; protected sections keep its updates from overwriting human corrections.

For [KI-PV-Assistent](https://github.com/aditya-ladawa/KI-Energie-Hackathon-Project), technical assessment and rule retrieval are deterministic. The LLM handles questions with citations alongside building and geospatial data.
